# DailyPulse – Daily News Web Application

**Stay informed. Stay ahead.**

DailyPulse is a responsive daily news web application that helps users explore the latest news from different categories in one place. It provides a simple and user-friendly interface to search, browse, and bookmark news articles.

## About the Project

DailyPulse is developed as a third-year B.Tech Computer Science Engineering project using HTML, CSS, and JavaScript. It integrates the GNews API to fetch news articles and display them dynamically.

The main objective of this project is to make accessing daily news easier through a clean and organized web interface.

## Features

- **Latest News:** Fetch and display news articles.
- **Category-wise News:** Browse Technology, Business, Sports, Health, Science, and Entertainment.
- **Search News:** Search for news using keywords.
- **Bookmark Stories:** Save interesting articles for later.
- **Dark Mode:** Switch between light and dark themes.
- **Read Original Article:** Visit the original news publisher.
- **Responsive Design:** Access the application on different screen sizes.

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Configure the required GNews API settings.
4. Run `index.html` using Live Server.
5. Explore the latest news and other features.
